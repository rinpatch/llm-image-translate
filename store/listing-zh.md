## Name (max 75)

LLM Image Translate：漫画、条漫与图片翻译

## Summary (max 132)

在任意网站翻译图片中的文字：用你的 ChatGPT 套餐、OpenRouter 免费模型、Chrome 内置翻译，或你自己的服务器。

## Description

直接在网页上翻译图片中的文字。漫画、条漫、X 上的帖子、Pixiv 作品、表情包、菜单、购物页面：原文会被抹去，译文写回原来的位置。结果是一张可以直接保存的普通图片。

用你已经有的
• 你的 ChatGPT 套餐：用 ChatGPT 登录，即可用 Plus、Pro、Business、Edu 或 Enterprise 套餐翻译。不用买点数，也不用额外订阅。
• OpenRouter：选一个免费模型，或每张图不到一美分的翻译模型。
• Chrome 内置翻译：免费，无需任何设置。
• 任意兼容 OpenAI 的服务器：llama.cpp、Ollama、LM Studio，或你自己的服务器。

看到哪，译到哪
• X（Twitter）、Pixiv、Naver Webtoon，以及任何其他网站。
• 为网站开启自动翻译后，图片会在你滚动到之前就译好。
• 按住 ⌘（其他系统为 Windows 键或 Super 键），图片上会出现标记，点击即可翻译；再点一次恢复原图。

为漫画和插画而做
• 识别日文、中文、韩文和英文，竖排横排都可以。
• 用基于漫画训练的修复模型抹去原文，对话框和背景保持干净。
• 可译成 20 种语言，包括中文、英文、俄文、印尼文、西班牙文和葡萄牙文。

无需注册账号
• 文字在你的电脑上、在浏览器里识别。
• 图片不会离开你的电脑：只有识别出的文字会发给你选的翻译服务。
• 无需注册，没有追踪，没有广告。
• 以 GPL-3.0 开源：https://github.com/rinpatch/llm-image-translate

通过“使用 ChatGPT 登录”产生的用量计入你的 ChatGPT 套餐额度。ChatGPT 是 OpenAI 的商标；本扩展与 OpenAI、X、Pixiv 和 Naver 均无关联。
