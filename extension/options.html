Image Translate

A reader finds the text, a translator translates it.

Profile

A reader and a translator under one name, switchable from the popup.

Reader

Finds the text in the image and reads it.

One request per image, and the model sees the page as it translates. No separate translator is used.

Adapter

Picked from the model. Change it for a model that answers in a different shape.

Translator

Turns what the reader found into the target language.

Chrome translates on this machine, one pair of languages at a time. Each pair is downloaded once, from here.
